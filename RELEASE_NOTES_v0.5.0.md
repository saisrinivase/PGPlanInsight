# pgplan_v0.5.0 — Evidence-to-resolution release

## Product value beyond PEV2

- Separates captured proof, diagnostic hypotheses, and facts the plan cannot establish.
- Shows where a symptom is observed and the deepest operation supported by matching evidence.
- Converts every finding into a controlled experiment with prerequisites, one action, success criteria, and rollback boundary.
- Imports an optional sanitized browser-session database context without credentials or a backend.
- Detects an existing leading-column index in imported context and withholds duplicate-index advice.
- Gates before/after verdicts on equivalent SQL shape, representative parameters, comparable environment/settings, measured runtime, and repetition status.

## Verification

- Deterministic domain and boundary tests cover unsafe comparison rejection, context validation, duplicate-index detection, experiment completeness, root-cause tracing, and enterprise plans.
- Playwright workflows cover PEV2 rendering, production TEXT plans, type coercion, context-qualified indexes, and guarded Fix Validation.
